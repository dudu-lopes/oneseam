# Code of Conduct

## Our Commitment
We are committed to a professional, respectful, and inclusive community focused on high-quality engineering work.

## Expected Behavior
- Be respectful and constructive.
- Focus discussions on technical merit and reproducible facts.
- Report security issues privately.
- Accept feedback and collaborate in good faith.

## Unacceptable Behavior
- Harassment, hate speech, intimidation, or personal attacks.
- Publishing private information without consent.
- Disruptive behavior that prevents productive collaboration.

## Enforcement
Project maintainers may edit, remove, or reject contributions and community interactions that violate this code.

## Scope
This code applies to repository discussions, issues, pull requests, and all project communication channels.
