# Examples

This folder contains runnable snippets for local integration experiments.

- `simple_swap.py`: minimal example for creating an intent and querying status via API.

Run:
```bash
python examples/simple_swap.py
```

Set `ONESEAM_API_BASE` if your API is not `http://127.0.0.1:8000`.
